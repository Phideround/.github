# Phideround organization profile

This repository holds the profile shown on <https://github.com/Phideround>. The content is in [`profile/README.md`](profile/README.md).

Phideround builds [RealMarketAPI](https://realmarketapi.com), a real-time market data API for developers and AI agents, and maintains its open-source SDKs, Agent Skills, examples and tools.

To suggest a change to the profile, open a pull request against `profile/README.md`.
